# FE Jira Backlog - 2026-04-27

## 기준
- 이번주는 디자인 완성보다 기능 골격 관통을 목표로 한다.
- 공통 컴포넌트와 훅을 먼저 만든 뒤 각 페이지에서 재사용한다.
- API가 준비되지 않은 기능은 mock adapter로 연결하고, 실제 API 연동 티켓은 후속으로 분리한다.
- 완료 기준은 "페이지 진입 가능, 주요 액션 가능, 상태 표시 가능, 다음 화면 연결 가능"이다.
- 디자인 polish, 모션 디테일, 픽셀 단위 정리는 다음 스프린트 backlog로 넘긴다.
